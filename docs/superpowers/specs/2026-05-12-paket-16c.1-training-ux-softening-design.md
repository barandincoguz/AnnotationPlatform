# Paket 16c.1 — Training UX Softening (Design)

**Status**: Draft — design phase
**Date**: 2026-05-12
**Builds on**: Paket 16c (tag `paket-16c-onboarding`) + Dalga 1 hardening
**Type**: Small extension (16c.1) — not a major package

---

## 1. Goal & Scope

The 16c training gate is too brittle for first-time bursiyer users:
- Frontend forces a non-empty `source_text` on every reference even though the backend matcher ignores `source_text` entirely.
- Backend concept matching is byte-exact, so trivial differences (`"5"` vs `"5 "`, `"a"` vs `"A"`, `"Geçici  67"` with double-space) cause unnecessary failures.
- A bursiyer who genuinely cannot pass training has no escape hatch — they get locked out after 3 attempts (Paket 10 limit).
- A bursiyer who is stuck on a single doc has no way to see the expected answer to learn from it.

This package softens all three friction points without weakening the main annotation (16b) save path.

### 1.1 In scope

1. **Backend string normalization** in `match_concept` — NFC + lowercase (Turkish-safe) + whitespace trim + internal-whitespace collapse + leading-zero strip on pure-numeric tokens. `source_text` exclusion is **unchanged** (was already in place).
2. **Backend `/api/training/start` payload** — adds `expected_concepts` per gold doc to the response (currently stripped). Required for the reveal panel.
3. **Backend new endpoint** `POST /api/training/skip` — auth + idempotent + writes audit_log row `training_skipped`.
4. **Frontend training-variant validator** in `lib/validateReferences.ts` — `isValidTrainingReference(r)` returns true if `r.kanun_no` OR `r.kanun_ad` is non-empty (source_text optional).
5. **Frontend AnnotateStep — reveal panel** — `[👁 Cevabı göster]` outline button next to Submit; collapsible card with `expected_concepts` formatted as text.
6. **Frontend Training route — skip link** — top-right small red link `Eğitimi geç (önerilmez)` visible on Start/Quiz/Annotate steps (NOT on Summary).
7. **Frontend `SkipConfirmDialog`** — Radix Dialog with "SKIP" typed-confirmation gate.
8. **Frontend `useSkipTrainingMutation`** — POSTs `/api/training/skip`, refreshes auth, navigates to `/`.

### 1.2 Out of scope

- Main annotation (16b) `isValidReference` — stays strict (source_text required).
- Re-take after skip — `has_passed_training=1` is terminal in this package; user cannot return to training. (Future package may add a `has_passed_training=2` 'skipped' tri-state with a reset path.)
- Pre-training notification visibility — still 16c carryover; addressed in a later package.
- Admin notification on skip — only audit_log entry in this package; admin panel (16e) will surface audit history.
- Token-level fuzzy matching (Levenshtein etc.) — string normalization only, not fuzzy distance.

## 2. Locked Design Decisions

| # | Decision | Rationale |
|---|---|---|
| D1 | Normalization scope = NFC + lowercase + trim + whitespace collapse + leading-zero strip on numeric tokens | User chose "source_text optional + string normalize (lowercase, trim, sayı norm)". This is the minimal set that captures the user's intent without introducing fuzzy distance semantics that could hide real errors. |
| D2 | Reveal panel = always available, no penalty, no mutation, no audit | User chose "Her zaman açık, panel açılıp kapanır, ceza yok (öğretici mod)". The training gate is a learning tool, not a gate-keeping exam in 16c.1 — strict gating already exists via 3-attempt lockout. |
| D3 | Skip = "SKIP" typed-confirmation + bypass + audit log | User chose "Onay + 'SKIP' yazması + bypass + audit log". Single click is too easy to misfire; admin oversight comes via audit_log review (16e). |
| D4 | Skip link placement = every training step's top-right | User chose "Her sayfanın üst sağ köşesinde küçük kırmızı link". Users may realize partway through that they want to skip, not only at Start. |
| D5 | Skip target = `has_passed_training=1` (same as passing) | Idempotent; no new column; reuses existing gate. Skip-then-retake is explicitly out of scope. |
| D6 | `expected_concepts` shipped in start payload | Reveal panel needs them. The Codex review's "answer leakage" concern is moot under D2 ("no penalty"). |
| D7 | Backend matching uses the SAME normalization for both training and any future caller of `match_concept` | One normalization function; no code path divergence. (Today `match_concept` is only called from training — but the contract stays consistent for future reuse.) |

## 3. Backend Contract

### 3.1 Normalization helper (NEW in `backend/training/matching.py`)

```python
import unicodedata


def _normalize_value(v) -> str | None:
    """Normalize a concept/reference field value for tolerant comparison.

    Pipeline:
      1. None or empty → return as-is (preserves wildcard semantics).
      2. unicodedata.normalize('NFC', str(v)) — combine code points.
      3. .strip().lower() — Turkish-safe; Python's str.lower() handles İ→i̇.
      4. Strip the combining dot above (U+0307) introduced by step 3 on İ.
      5. " ".join(s.split()) — collapse runs of whitespace to single space.
      6. For each space-separated token that is pure-digit: strip leading
         zeros (but keep "0" as "0", never empty).
    """
    if v is None:
        return None
    s = unicodedata.normalize("NFC", str(v))
    if not s.strip():
        return ""
    s = s.strip().lower().replace("̇", "")
    s = " ".join(s.split())
    parts = s.split(" ")
    out_parts: list[str] = []
    for p in parts:
        if p.isdigit():
            out_parts.append(p.lstrip("0") or "0")
        else:
            out_parts.append(p)
    return " ".join(out_parts)
```

### 3.2 `match_concept` rewrite

```python
def match_concept(concept: dict, references: Iterable[dict]) -> bool:
    constraints_raw = _concept_constraints(concept)  # unchanged: filters
                                                     # source_text + empties
    constraints = {k: _normalize_value(v) for k, v in constraints_raw.items()}
    if not constraints:
        return any(True for _ in references)
    for r in references:
        normed = {k: _normalize_value(r.get(k)) for k in constraints}
        if all(normed.get(k) == v for k, v in constraints.items()):
            return True
    return False
```

The two existing helpers `score_quiz`, `match_gold_doc`, `is_doc_pass`, `_concept_constraints` are **unchanged**.

### 3.5 NEW endpoint `POST /api/training/skip`

```python
@router.post("/skip", response_model=OkResponse)
def skip_training(
    db: sqlite3.Connection = Depends(get_db),
    user: sqlite3.Row = Depends(get_current_user),
):
    """Bypass the training gate: sets has_passed_training=1 immediately
    and writes an audit_log entry. Idempotent — re-calling on a user
    who already passed (or skipped) is a no-op."""
    service.skip_training(db, user_id=user["id"])
    return {"ok": True}
```

### 3.6 NEW service function `skip_training`

```python
def skip_training(db: sqlite3.Connection, *, user_id: int) -> None:
    row = db.execute(
        "SELECT has_passed_training FROM users WHERE id=?", (user_id,)
    ).fetchone()
    if row is None:
        raise UserNotFound(user_id)
    if row["has_passed_training"]:
        return  # idempotent — already passed or already skipped
    trace_id = audit.gen_trace_id()
    db.execute(
        "UPDATE users SET has_passed_training=1, updated_at=datetime('now') "
        "WHERE id=?",
        (user_id,),
    )
    # audit.log signature varies — implementer matches the existing call
    # pattern in backend/shared/audit.py (used by users.service.promote_admin
    # etc.). At minimum: event="training_skipped", user_id, trace_id, and
    # a detail blob noting actor="self".
    audit.log(
        db, event="training_skipped", user_id=user_id, trace_id=trace_id,
        detail={"actor": "self"},
    )
    db.commit()
```

Auth: `get_current_user` — pre-training users CAN call this (whole point). Admin not required.

## 4. Frontend

### 4.1 `lib/validateReferences.ts` — add training variant

The strict `isValidReference` and `areAllReferencesValid` stay byte-identical (16b/Dalga 1 contract). Add **alongside**:

```ts
/**
 * Training variant: source_text is optional (backend doesn't compare it).
 * Still requires at least one of {kanun_no, kanun_ad} so the reference is
 * meaningful enough for concept matching.
 */
export function isValidTrainingReference(r: ReferenceItem): boolean {
  const hasKanunNo = (r.kanun_no?.trim() ?? '') !== ''
  const hasKanunAd = (r.kanun_ad?.trim() ?? '') !== ''
  return hasKanunNo || hasKanunAd
}

export function areAllTrainingReferencesValid(refs: ReferenceItem[]): boolean {
  return refs.every(isValidTrainingReference)
}
```

`AnnotateStep.tsx` swaps `areAllReferencesValid` → `areAllTrainingReferencesValid` (single-line import change).

`formatConcept` lives in `lib/formatTrainingConcept.ts` (see §5.1 — separate file for testability):
```ts
const REQUIRED_KEYS = ['kanun_no', 'kanun_ad', 'madde'] as const
const OPTIONAL_KEYS = ['fikra', 'bent'] as const

export function formatConcept(c: Record<string, string | null | undefined>): string {
  const required = REQUIRED_KEYS
    .filter((k) => c[k])
    .map((k) => `${k}: ${c[k]}`)
    .join(', ')
  const optional = OPTIONAL_KEYS
    .filter((k) => c[k])
    .map((k) => `(${k}: ${c[k]})`)
    .join(' ')
  return [required, optional].filter(Boolean).join(' ')
}
```

Example output: `kanun_no: 5520, madde: 5 (fikra: 1) (bent: a)`

### 4.5 `useSkipTrainingMutation`

In `api/queries/training.ts`:

```ts
export function useSkipTrainingMutation() {
  const qc = useQueryClient()
  const navigate = useNavigate()
  return useMutation({
    mutationFn: async () =>
      unwrapVoid(await client.POST('/api/training/skip')),
    onSuccess: async () => {
      await refreshAuth()                      // Dalga 1 helper
      qc.invalidateQueries()                   // clear stale gate state
      toast.warning('Eğitim atlandı. İyi şanslar.', { duration: 5_000 })
      navigate('/', { replace: true })
    },
    onError: () => {
      toast.error('Eğitim atlanamadı. Lütfen tekrar dene.')
    },
  })
}
```

`refreshAuth()` lives in `lib/refreshAuth.ts` (added by Dalga 1; pulls `/api/auth/me`, updates `useAuthStore.setUser`).

## 9. Manual E2E Smoke

Open `http://localhost:5173`:

1. Fresh user (has_passed_training=0). Navigate to `/training`. Skip link visible top-right.
2. Click **Eğitime Başla**, complete Quiz, reach AnnotateStep doc 1.
3. Enter a reference with `kanun_no="5520"`, `madde="5"`, leave source_text **empty**. Submit button → ENABLED. Submit → passes (matched_count ≥ 1).
4. Doc 2: Enter `kanun_no="3065"`, `madde="29 "` (trailing space). Submit → passes (normalization).
5. Doc 3: Click **👁 Cevabı göster** — panel opens with 2 concepts: `kanun_no: 193, madde: Geçici 67` and `kanun_no: 193, madde: Mükerrer 80`. Enter one of them with case difference: `kanun_no="193"`, `madde="geçici 67"` (lowercase). Submit → passes.
6. Click **Eğitimi geç (önerilmez)** during any step. Dialog opens. Type "skip" (lowercase) → "Eğitimi Atla" disabled. Type "SKIP" → enabled. Click "Vazgeç" → dialog closes, training unchanged.
7. Re-open dialog. Type "SKIP". Click "Eğitimi Atla". Toast "Eğitim atlandı". Lands on `/` (Annotate feed). TopBar visible (RequirePassedTraining passed).
8. Open second tab → `/me` → still works (has_passed_training=1).
9. Query DB: `SELECT * FROM audit_log WHERE event='training_skipped'` → one row for this user.
10. As admin (separate session): hit `/api/training/start` for the just-skipped user impersonation isn't possible; verify the audit_log row exists instead.

## 10. Risks & Open Questions

**Accepted limitations**:
- Skipped users cannot return to training in this package (terminal `has_passed_training=1`).
- Normalization does NOT do fuzzy distance (Levenshtein, soundex) — typos like `"5520"` vs `"552O"` (letter-O for digit-0) still fail. Acceptable; would obscure real errors otherwise.
- `expected_concepts` leak via DevTools is accepted under D2 ("no penalty"). Future package may add a "non-leak mode" toggle for admins running quality audits.

**Risks under mitigation**:
- Backend `match_concept` is called only in training service today; normalization side effect on hypothetical future callers is bounded by D7 documentation.
- New `@radix-ui/react-dialog` dep: ~30KB minified — acceptable; consistent with shadcn pattern.
- `useSkipTrainingMutation` invalidates ALL queries to force gate re-evaluation. This is heavy but rare (one-time action). Cheaper than enumerating affected keys.

**No open questions**. All gray areas resolved through Q&A.
