# Presentation Layout Catalog & Design Rules

## Supported Layout Types

1. **Title Slide (`title`)**: Dark Slate theme (`#0F172A`), outcome title, subtitle, divider accent line, and author metadata.
2. **Big Stat Callout (`bigStat`)**: 3-column metric cards with large bold numbers (48pt), title labels, and impact descriptions.
3. **Two-Column Features (`twoColumn`)**: Side-by-side comparison boxes with distinct header color badges and bulleted features.
4. **Comparison Matrix (`comparison`)**: Structured PowerPoint data table with colored header row and alternating row styling.
5. **Process Workflow (`process`)**: 4-stage sequential workflow cards with numbered oval badges and connecting right arrows.
6. **Native PowerPoint Chart (`chart`)**: Native PPTX bar/column chart component (`pptx.addChart`) paired with right-side commentary panel.
7. **Technical Architecture (`techArchitecture`)**: 3-layer system topology boxes with header banners and bulleted capabilities.
8. **Summary & Conclusion (`summary`)**: Executive takeaway card paired with numbered action items checklist.

## Visual Design Rules

- **Ratio**: 16:9 Widescreen (13.333" x 7.5").
- **Margin Bounds**: Left margin = 0.8", Header Y = 0.8", Content Y = 1.9" to 6.8".
- **Typography**: Calibri (Titles 22-36pt bold, Body 12-16pt).
- **Contrast**: Pure dark slate `#0F172A` on `#F8FAFC` light card background.
